# Research

This folder contains supporting research materials, literature reviews, data, and academic references.

## 📚 What Goes Here?

### Literature Reviews
- Summaries of relevant academic papers
- Industry reports and whitepapers
- Blog posts and articles
- Books and resources

### Data & Evidence
- Survey results
- User research findings
- Market analysis
- Statistics and metrics

### Case Studies
- Similar projects or ideas
- Success/failure analyses
- Lessons learned from others

### References
- Citations and bibliography
- Links to external resources
- Academic papers (PDF or links)

## 📝 Organization

Organize content by type or topic:

```
research/
├── README.md
├── literature-review.md          # Comprehensive literature review
├── user-research.md              # User interviews, surveys
├── market-analysis.md            # Market research, competitors
├── papers/                       # Academic papers (PDFs)
│   ├── paper-1.pdf
│   └── paper-2.pdf
├── data/                         # Datasets, CSVs, etc.
│   └── survey-results.csv
└── case-studies/                 # Individual case studies
    ├── similar-project-1.md
    └── similar-project-2.md
```

## 🔗 Linking Research to Docs

Reference research materials in your main documentation:

- `problem_statement.md` — Cite evidence for the problem
- `idea.md` — Reference inspirations and prior art
- `scope.md` — Use data to inform scope decisions

Example:
```markdown
Research shows that [claim] (see [literature-review.md](./research/literature-review.md#section))
```

## ✍️ Citation Format

Use a consistent citation style (APA, MLA, or simple format):

**Simple format:**
```markdown
Author Name. "Title of Work." Publication/Source, Year. URL
```

**Example:**
```markdown
Smith, J. "Knowledge Management in Teams." Journal of Collaboration, 2025. https://example.com/paper
```

## 📊 Data Guidelines

- Include sources for all data
- Provide context and methodology
- Store raw data when possible
- Include data dictionaries if needed
