## 🤝 How to Contribute

We welcome contributions of all kinds! Here's how you can help:

### Types of Contributions

- **💻 Code** — Implementation, bug fixes, optimizations
- **📝 Documentation** — Writing, editing, translating docs
- **🎨 Design** — UI/UX, graphics, visual assets
- **🔬 Research** — Papers, case studies, data analysis
- **💬 Discussion** — Ideas, feedback, decision-making
- **🐛 Testing** — Bug reports, QA, user testing
- **📣 Advocacy** — Spreading the word, presentations

### Getting Started

1. Read the [idea documentation](./) to understand the concept
2. Check the [scope](./scope.md) to see what's in progress
3. Look for open issues or discussions in the main repository
4. Join our community on [Discord/Slack/etc.]
5. Introduce yourself and share how you'd like to contribute

### Contribution Guidelines

- Follow the documentation structure in `.humanet/templates/`
- Use draw.io for all diagrams (source `.drawio` files required)
- Update `CHANGELOG.md` when making significant changes
- Be respectful, inclusive, and collaborative

## 🎖️ Karma System

Humanet uses a karma system to recognize all types of contributions (not just code!).

### How Karma is Earned

- **Code contributions:** Pull requests merged
- **Documentation:** New docs, significant edits
- **Research:** Papers, case studies, data
- **Design:** UI/UX work, graphics
- **Community:** Helping others, discussions
- **Advocacy:** Talks, blog posts, tutorials

### Karma Distribution

Karma is distributed by maintainers and tracked automatically by the Humanet platform.
