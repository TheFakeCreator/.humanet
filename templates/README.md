# Templates

Reusable templates for common documentation needs.

## 📄 Available Templates

### Decision Record Template
Use for Architecture Decision Records (ADRs) and important decisions.

**File:** [`decision-record.md`](./decision-record.md)

**When to use:**
- Making architectural choices
- Selecting technologies
- Deciding on approach or strategy
- Resolving design debates

### Meeting Notes Template
Use for planning meetings, brainstorms, and discussions.

**File:** [`meeting-notes.md`](./meeting-notes.md)

**When to use:**
- Team meetings
- Stakeholder discussions
- Planning sessions
- Brainstorming workshops

### Research Summary Template
Use for summarizing papers, articles, or case studies.

**File:** [`research-summary.md`](./research-summary.md)

**When to use:**
- Reviewing academic papers
- Analyzing competitor products
- Case study analysis
- Industry report summaries

## 🚀 Using Templates

### Copy and Rename

```bash
# Copy template to discussions folder
cp .humanet/templates/decision-record.md .humanet/discussions/002-my-decision.md

# Copy template to research folder
cp .humanet/templates/research-summary.md .humanet/research/paper-summary.md
```

### Fill Out Sections

Replace placeholder text with your content:
- `[Placeholder]` — Replace with actual content
- `[Delete if not applicable]` — Remove section if not needed
- Optional sections marked clearly

### Follow Conventions

- Use consistent naming (lowercase, hyphens)
- Date stamp when relevant
- Link related documents
- Update last modified date

## ✏️ Customizing Templates

Feel free to modify templates to fit your needs:
- Add sections that are relevant to your project
- Remove sections that don't apply
- Create new templates for recurring document types
