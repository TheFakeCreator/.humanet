# Diagrams

This folder contains all visual documentation for the idea.

## 📐 Diagram Guidelines

### File Formats

- **Source files:** `.drawio` (required — editable diagrams)
- **Export files:** `.png` or `.svg` (for embedding in markdown)

### Tools

**Primary:** [draw.io](https://draw.io) / [diagrams.net](https://diagrams.net)

- ✅ Free and open source
- ✅ Works in browser or desktop
- ✅ Git-friendly `.drawio` format
- ✅ Integrates with GitHub

### Naming Convention

Use descriptive, lowercase names with hyphens:

```
architecture-overview.drawio
architecture-overview.png

user-flow.drawio
user-flow.png

data-model.drawio
data-model.png
```

## 📊 Common Diagram Types

### Architecture Diagrams
- System architecture

### Flow Diagrams
- User flows
- Data flows
- Process flows
- Decision trees

### Conceptual Diagrams
- Mind maps
- Concept maps
- Knowledge graphs
- Relationship diagrams

### Technical Diagrams
- Database schemas
- API structures
- Class diagrams
- Sequence diagrams

## 🎨 Best Practices

1. **Keep it simple** — One diagram, one concept
2. **Use consistent styling** — Colors, fonts, shapes
3. **Label everything** — Clear, concise labels
4. **Version your diagrams** — Include version number or date if helpful
5. **Export for docs** — Always export as PNG/SVG for README embedding

## 📤 Exporting from draw.io

1. File → Export as → PNG (or SVG)
2. Settings:
   - ✅ Transparent background (for PNG)
   - ✅ Include a copy of my diagram
   - Resolution: 2x or 3x for high quality

## 🔗 Embedding in Documentation

```markdown
![Architecture Overview](./diagrams/architecture-overview.png)
```
