# Evaluations

This folder contains AI-generated validation reports and quality assessments.

## 🤖 About AI Evaluations

The Humanet platform uses AI to evaluate ideas during the **Provisional** phase. This ensures quality and completeness without manual gatekeeping.

## 📊 What Gets Evaluated?

### Documentation Quality
- **Clarity:** Is the problem and solution well-articulated?
- **Completeness:** Are all required documents present and filled out?
- **Specificity:** Are claims specific and actionable?

### Idea Viability
- **Feasibility:** Can this realistically be built?
- **Impact:** What's the potential positive change?
- **Originality:** Is this novel or an improvement on existing solutions?

### Evaluation Criteria

Each idea is scored on a scale of 0-10 across multiple dimensions:

| Criterion | Weight | Description |
|-----------|--------|-------------|
| **Clarity** | 20% | Problem and solution are clearly explained |
| **Feasibility** | 25% | Idea is achievable with available resources |
| **Impact** | 25% | Potential to create meaningful change |
| **Originality** | 15% | Novelty and unique value proposition |
| **Completeness** | 15% | Documentation is thorough and well-structured |

**Total Score:** Weighted average (0-10)

### Validation Outcomes

- **8-10:** ✅ **Validated** — Idea moves to Active status
- **6-7.9:** ⚠️ **Needs Refinement** — Feedback provided, resubmit for evaluation
- **0-5.9:** ❌ **Vague** — Significant improvements needed

## 📄 Evaluation Report Format

Each evaluation generates a report saved in this folder:

```
evaluations/
├── README.md
├── 2026-02-15-initial-evaluation.md
├── 2026-03-01-re-evaluation.md
└── validation-passed.md
```

### Report Contents

- Overall score and status
- Dimension-by-dimension breakdown
- Strengths identified
- Areas for improvement
- Specific recommendations
- Links to relevant sections

## 🔁 Re-evaluation Process

If your idea needs refinement:

1. Review the AI feedback carefully
2. Make improvements to your documentation
3. Request re-evaluation (automatic or manual)
4. New evaluation report generated

## 🎯 Improving Your Score

### To Improve Clarity
- Use specific language, avoid vague terms
- Provide concrete examples
- Break down complex concepts
- Add diagrams where helpful

### To Improve Feasibility
- Show you've researched similar solutions
- Identify available resources
- Acknowledge risks and mitigation plans
- Provide a realistic timeline

### To Improve Impact
- Quantify the problem scale
- Define measurable success criteria
- Show potential for positive change
- Connect to real user needs

### To Improve Originality
- Clearly differentiate from existing solutions
- Explain your unique approach
- Reference prior art and how you're different

### To Improve Completeness
- Fill out all required documents thoroughly
- Add supporting materials (diagrams, research)
- Include decision logs and rationale
- Provide comprehensive scope definition

## 🤝 Human Review

While AI handles initial validation, the Humanet community can also:
- Provide feedback and suggestions
- Vote on ideas
- Offer expertise and mentorship
- Collaborate on refinements

AI evaluation is a quality baseline, not a replacement for human collaboration.
